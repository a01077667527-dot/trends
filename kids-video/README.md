# 동물 친구들과 숫자 놀이 (1~10)

어린이용 숫자 학습 2D 애니메이션 — `animal_numbers.mp4` (1920x1080 Full HD, 30fps, 약 2분 10초)

캐릭터·배경·글자를 모두 벡터로 직접 그린 오리지널 애니메이션입니다.
- 동물 친구들이 눈을 깜빡이고, 숨 쉬고, 점프할 때 몸이 눌렸다 늘어나요 (스쿼시 & 스트레치)
- 오른쪽에서 포물선을 그리며 뛰어 들어와 착지하면 흙먼지가 일고, 배에 번호가 생겨요
- 해님·구름·언덕·나무·꽃이 움직이는 배경, 장면마다 원형 와이프 전환
- 글자가 한 자씩 통통 튀며 나타나요

## 구성
| 장면 | 동물 친구 | 자막 |
|---|---|---|
| 인트로 | 동물 친구 10마리 | 동물 친구들과 숫자 놀이! |
| 1 하나(일) | 강아지 | 강아지가 한 마리 있어요! |
| 2 둘(이) | 고양이 | 고양이가 두 마리 있어요! |
| 3 셋(삼) | 토끼 | 토끼가 세 마리 있어요! |
| 4 넷(사) | 병아리 | 병아리가 네 마리 있어요! |
| 5 다섯(오) | 곰돌이 | 곰돌이가 다섯 마리 있어요! |
| 6 여섯(육) | 펭귄 | 펭귄이 여섯 마리 있어요! |
| 7 일곱(칠) | 아기 돼지 | 아기 돼지가 일곱 마리 있어요! |
| 8 여덟(팔) | 개구리 | 개구리가 여덟 마리 있어요! |
| 9 아홉(구) | 판다 | 판다가 아홉 마리 있어요! |
| 10 열(십) | 햄스터 | 햄스터가 열 마리 있어요! |
| 아웃트로 | 열 친구 모두 (1~10 복습) | 참 잘했어요! 다음에 또 만나요~ 안녕! |

동물이 한 마리씩 "폴짝" 뛰어 들어오고, 말풍선으로 "하나, 둘, 셋…" 세어 줍니다.
배경음악(오리지널 멜로디: 글로켄슈필·마림바·베이스·드럼)과 효과음은 코드로 직접 합성했습니다 (저작권 걱정 없음). 내레이션 음성은 없으니,
필요하면 위 자막을 읽어 녹음해서 덧입히면 됩니다.

## 다시 만들기
```bash
python3 make_video.py
```
필요: Python 3, pycairo, numpy, fonttools, ffmpeg (`pip install pycairo numpy fonttools`).
`python3 make_video.py --preview 폴더` 로 몇 장면만 PNG로 미리 볼 수 있어요.
글꼴: Jua (SIL Open Font License, `fonts/OFL-Jua.txt`).
